# Welcome!
This is a repository for the source code of my portfolio website. I have chosen to build my site using a basic vanilla tech stack using HTML, CSS, and Javascript.

### Hosting
I am using a simple setup to host my website. I am using Github pages as the backend webserver to serve my templates, with a custom domain name purchased from Namecheap!

Here is a great educational resource that explains the entire process to host a static website such as my portfolio: https://www.youtube.com/watch?v=p1QU3kLFPdg
